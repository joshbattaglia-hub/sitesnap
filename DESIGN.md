# SiteSnap MVP — visual direction

Contractor daily site photos. **Not** Liberty retail branding.

## Principles
- Dead simple on site (one thumb, gloves OK)
- Admin is clear and sparse — find a site, see photos by day
- Practical, modern, high clarity

## Tokens
- Font: Inter / system UI
- BG `#F3F4F6` · Surface `#FFFFFF` · Text `#111827` · Muted `#6B7280`
- Accent `#0F766E` (teal — construction/practical, not Liberty red)
- Radius 12–16px · Large tap targets (48px+)

## Screens
1. **Uploader** (mobile-first, no library nav)
   - Site name (text or select if pre-created)
   - Huge photo/camera button
   - Optional note
   - Primary Upload
2. **Admin**
   - Password gate
   - Site list (+ create site)
   - Site detail: date groups, photo grid, copy upload link
